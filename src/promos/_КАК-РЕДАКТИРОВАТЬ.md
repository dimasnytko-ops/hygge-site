# Как менять акции

Каждая акция — отдельный файл `.md` в этой папке. Файлы, имя которых начинается с `_`, на сайт не попадают (как этот).

## Шаблон

```
---
title: Короткий заголовок акции
kind: постоянная        # или: временная
active: true            # false — спрятать акцию, не удаляя файл
order: 3                # порядок на сайте: меньше — выше
until: 2026-12-31       # только для временных: после этой даты акция скроется сама
---
Условия акции обычным текстом. Можно несколько абзацев.
```

## Что можно делать
- **Изменить условия** — поправьте текст или заголовок в файле.
- **Добавить акцию** — скопируйте любой файл, дайте ему новое имя (латиницей, например `new-year.md`) и поменяйте текст.
- **Убрать акцию** — поставьте `active: false` или удалите файл.
- **Временная акция** — `kind: временная` и дата `until`. Первая активная временная акция показывается полосой вверху главной страницы.

После изменения сайт нужно пересобрать (`npm run build`) и выложить заново — когда будет хостинг, это будет происходить автоматически.
